# Davis/Wu piecewise PV inversion — gfortran port

Faithful port of the three Fortran-77 programs from the Davis/Wu PV-inversion
tutorial (`pv_inversion/archive/talia_tutorial/inv3d/`) so they compile with
`gfortran -std=legacy` on Linux, plus sed-generated 9-level (CESM wu9) and
larger-outer-domain build variants.

```
pv_inversion_talia/
  src/        pvpialln_94UV.f  qinvert21_94.f  qinvertp21_94.f   (patched, minimal diffs)
  build/      the 9 binaries
  build/gen/  sed-generated 9-level source variants
  Makefile
  NOTES.md    (this file)
```

Pipeline: `pvpialln` (grid -> PV + streamfunction) -> `qinvert` (total
nonlinear-balance inversion) -> `qinvertp` (perturbation piecewise inversion).

## 1. Build

```
cd /net/flood/data2/users/x_yan/pv_inversion_talia
```

silences legacy-extension warnings such as REAL DO bounds and REAL array

The NYxNX-suffixed variants are alternate window geometries for the
boundary-condition robustness matrix (Makefile `SIZES`); they differ from
inner9 only in the `PARAMETER NY/NX` values.  A grid must exactly match its
binary's compiled size (the pass-D `BALP` subroutine loops over the
compile-time parameters, not the header).

reg10 compiles `src/` directly and exists only to regress against the shipped
tutorial outputs. The 9-level variants are generated by sed into `build/gen/`
(`src/` stays pristine); the sed edits replace only the `PARAMETER` values
(`NW=10`/`NL=10` -> 9; outer9 additionally `NY=21` -> 25, `NX=45` -> 89 — the
parameters are declared in each program unit AND its subroutine, and sed
replaces every occurrence, which is required: main and subroutine dimensions
must agree) and the one active (tab-indented) `DATA PR/.../` statement per
file. Every other level-dependent quantity is already written in terms of
NW/NL and self-adjusts: `PIB/PIT` (pvpialln), `DPI=500./FLOAT(NL)` (qinvert21
as shipped; qinvertp21 after the patch below), the `BB/BH/BL/DPI2` vertical
operators, and all array bounds. The nondimensional height scale
HND = FF^2 * LL^2 / GG is independent of NL (the DPI factors cancel), so the
9-level variants change no scaling conventions.

Relaxation-parameter guidance from the original documentation: OMEGAS ~1.6 for
a ~20x20 grid, ~1.85-1.9 for ~40x40. The deck values 1.85/1.75 work for both
the 45x21 and 89x25 grids.

## 2. Source changes (complete list)

Four categories, nothing else: (1) VAX `TYPE*` -> standard `PRINT*`;
(2) `OPEN(...,STATUS='new')` -> `'unknown'` so reruns do not abort on existing
output files; (3) iteration-cap bumps for the larger outer domain
(`pvpialln` `imax` 300 -> 2000; `qinvertp21` `MAX`/`MAXT` 400 -> 2000;
`qinvert21` takes MAX/MAXT from its deck, so no source change — use 2000 in
decks for large domains); (4) two correctness/consistency fixes:
`PI(10)` -> `PI(NW)` in pvpialln (hardcoded dimension would silently desync
from the sed-built NW=9 variants), and zero-initialization of `HTSUM`/`SISUM`
at entry to `qinvertp21` subroutine `BALP` — with `IBC=1` these arrays are
read (piecewise-sum subtracted from the full perturbation) before they are
first written; the original VAX/static-allocation compilers zero-filled static
arrays and masked the bug, whereas gfortran leaves them as stack garbage.
`qinvertp21`'s `DPI=50.` (valid only for NL=10) becomes `DPI=500./FLOAT(NL)`,
matching what `qinvert21_94.f` already does. No I/O restructuring, no numeric
or formatting changes.

## 3. Grid and index conventions (all three programs)

* Header record (free format, 8 values):
  `SLAT WLON NLAT ELON DLON DLAT NX NY`.
  The code uses fields 3 (NLAT, northernmost latitude), 5 (DLON), 6 (DLAT),
  7 (NX), 8 (NY). Examples:
  * inner: `25.0 -75.0 75.0 35.0 2.5 2.5 45 21`
  * outer: `20.0 -130.0 80.0 90.0 2.5 2.5 89 25`
* Row index I runs north -> south: lat(I) = NLAT − (I−1)·DLAT, I=1..NY.
  Column index J runs west -> east, J=1..NX.
* Level index K runs bottom -> top through the `DATA PR` table (K=1 is
  1000 hPa; K=NW/NL is the top level).
* Every 2-D record set below is written row-major: NY records of NX values,
  I=1..NY, each row wrapped by its FORMAT.
* All headers written to output files are echoes of the input header via
  list-directed `WRITE(u,*)`; on read they are consumed list-directed, so
  header line-wrapping differences between compilers are harmless.
* Nondimensional scales used by qinvert/qinvertp: LL = AA·DLON·π/180 with
  AA = 2e7/π; FF = 1e-4; DPI = 500/NL; THO = FF²LL²/DPI;
  HND = DPI·THO/GG = FF²LL²/GG (≈ 78.7 m for DLON = 2.5°, independent of NL).

## 4. pvpialln (pass A/B): .grid -> q.out, h.out, meanq, meanh

### Deck (stdin), in READ order

| # | READ | meaning |
|---|------|---------|
| 1 | `READ(5,'(a)') F(2)` | output filename: time-mean THBm/THTm/Qm (`meanq`) |
| 2 | `READ(5,'(a)') F(3)` | output filename: time-mean Hm/psim (`meanh`) |
| 3 | `READ(5,*) nhalfday` | number of input half-days (max 50: INFILES is dimensioned 50) |
| 4..3+n | `READ(5,'(a)') INFILES(1..nhalfday)` | one .grid filename per line |
| next | `READ(5,*) nhalfdayo` | number of half-days to write per-day output for (max 23: per-day filenames land in F(4)..F(5+2·(nn−1)) and F is dimensioned 50; nhalfout itself is dimensioned 30) |
| then, repeated nhalfdayo times: | | |
| · | `READ(5,*) nhalfout(nn)` | which half-day (1-based index into INFILES) |
| · | `READ(5,'(a)')` | per-day q output filename (THB,THT,Q) |
| · | `READ(5,'(a)')` | per-day h output filename (H,psi,U,V,TH) |

Filenames are read with `(a)` — no quotes. `imax=2000`, `omegs=1.75`,
`thrs=5.e4` (SOR cap / relaxation / psi-increment threshold, m²/s) are
hardwired. All input .grid headers must be identical or the program stops.

### Input .grid layout

Header line, then 4 variables × NW levels × NY rows, `FORMAT(10F8.1)`
(a 45-value row occupies 5 lines; an 89-value row 9 lines):
`H` (geopotential height, m), `T` (temperature, K — converted internally to
theta), `U`, `V` (m/s). Level order bottom -> top.

### Per-day q output (`*q.out`), FORMAT(13F10.2)

| block | count | content |
|-------|-------|---------|
| THB | 1 × NY×NX | boundary theta at the lower half-level, 0.5·(TH(1)+TH(2)), K |
| THT | 1 × NY×NX | boundary theta at the upper half-level, 0.5·(TH(NW−1)+TH(NW)), K |
| Q | (NW−2) × NY×NX | Ertel-like PV at K=2..NW−1, units 0.01 PVU (values order 100); lateral boundary ring = 9999.90 (missing) |

### Per-day h output (`*h.out`), FORMAT(13F10.2)

| block | count | content |
|-------|-------|---------|
| H | NW × NY×NX | input heights, m |
| psi | NW × NY×NX | streamfunction inverted from relative vorticity, **written divided by 1.e5** (m²/s ×10⁻⁵, so numbers resemble heights) |
| U | NW × NY×NX | input U, m/s |
| V | NW × NY×NX | input V, m/s |
| TH | NW × NY×NX | theta, K |

### Time-mean outputs

`meanq` = THBm, THTm, Qm (same layout as q.out, averaged over all nhalfday
inputs). `meanh` = Hm then psim (psim also written /1.e5) — note meanh has
only the 2 blocks (no U/V/TH).

## 5. qinvert (pass C): h.out + q.out -> bal.out (total nonlinear balance)

### Deck (stdin), in READ order — all values list-directed, filenames quoted

| # | READ | meaning | shipped deck value |
|---|------|---------|--------------------|
| 1 | `MAX` | max SOR iterations per equation | 200 (use 2000 for the outer domain) |
| 2 | `MAXT` | max total psi/phi cycles | 200 (use 2000 for the outer domain) |
| 3 | `OMEGAS` | psi overrelaxation | 1.85 |
| 4 | `OMEGAH` | height overrelaxation | 1.75 |
| 5 | `PRT` | underrelaxation between the two equations | 0.5 |
| 6 | `THR` | convergence threshold, meters | 0.1 |
| 7 | `FNM(1)` | INIT file (h.out: H then psi initial guess) | `'03021312h.out'` |
| 8 | `FNM(2)` | Q file (q.out: THB,THT,Q) | `'03021312q.out'` |
| 9 | `FNM(5)` | output bal file | `'03021312bal.out'` |
| 10 | `IMAP` | 1 = spherical lat/lon, 2 = x/y map-factor | 1 |
| (10a) | `LLF` | map-factor/latitude file — **only if IMAP=2** | — |
| 11 | `QMIN` | floor for PV (PVU); negative/small PV is raised to it and the volume integral preserved | 0.01 |
| 12 | `INF` | 1 = INIT holds NL levels H then NL levels psi; ≠1 = INIT holds theta/psi | 1 |
| (12a) | `FNM(3)` | upper-b.c. height file — **only if INF≠1** | — |

With INF=1 only the first 2·NL 2-D blocks of the INIT file are read, so a full
5-block h.out works directly. Input units: H in m, psi in 10⁵ m²/s (i.e. the
h.out convention), Q in 0.01 PVU, THB/THT in K.

### bal.out layout, FORMAT(13F10.2)

Header, then:

| block | count | content |
|-------|-------|---------|
| HZ | NL × NY×NX | balanced geopotential height, m |
| SI | NL × NY×NX | balanced streamfunction, 10⁵ m²/s (same scaling as input psi) |

Numbers in the output have exactly the same units as the numbers in the input
(nondimensionalized by GG/(THO·DPI) on read, multiplied back on write).

## 6. qinvertp (pass D): piecewise perturbation inversion -> pert.out

### Deck (stdin), in READ order

| # | READ | meaning | shipped deck value |
|---|------|---------|--------------------|
| 1 | `OMEGAS` | psi overrelaxation | 1.85 |
| 2 | `OMEGAH` | height overrelaxation | 1.75 |
| 3 | `PRT` | underrelaxation | 0.8 |
| 4 | `THRSH` | convergence threshold, meters | 0.1 |
| 5 | `TSCAL` | scale factor on total boundary theta | 1. |
| 6 | `QSCAL` | scale factor on PV (declared; not applied in this code revision) | 1. |
| 7 | `FNM(1)` | mean q file (meanq: THBm,THTm,Qm) | `'meanq'` |
| 8 | `FNM(2)` | mean h file (meanh: Hm,psim — 2 blocks) | `'meanh'` |
| 9 | `FNM(3)` | total q file (q.out for the target time) | `'03021312q.out'` |
| 10 | `FNM(4)` | total h file — **the balanced bal.out** (H then psi), unit 4 | `'03021312bal.out'` |
| 11 | `FNM(5)` | output perturbation file | `'03021312pert.out'` |
| 12 | `IMAP` | 1 = spherical (IMAP=2 opens hardwired file `latlon`) | 1 |
| 13 | `INLIN` | 1 = keep nonlinear terms (mean := mean + ½·perturbation); required for piecewise sums to add to the total | 1 |
| 14 | `IQD` | 1 = threshold q′ on another gridded field (reads DPFIL, NDAYS, LPD, then one CRIT per interior level) | 0 |
| 15 | `NHO,(HOUT(i))` | # and ascending list of output HP levels | `10,1,...,10` (9-level: `9,1,...,9`) |
| 16 | `NSIO,(SIOUT(i))` | # and ascending list of output SP levels | `10,1,...,10` |
| 17 | `NOUT` | number of piecewise inversions in this run | 3 |
| then, repeated NOUT times: | | | |
| · | `NMLV,(QLV(i))` | # and list of PV pieces for this inversion: 1 = lower boundary theta, 2..NL−1 = interior PV levels, NL = upper boundary theta | e.g. `1,1` / `2,2,3` / `7,4,...,10` |
| · | `IBC` | lateral b.c.: 0 = homogeneous Dirichlet; 1 = full perturbation on the boundary; 2 = read initial-guess/boundary file | 0 |
| · | `IGFIL` | initial-guess filename — **only if IBC=2** | — |

Perturbations are formed internally: q′ = totalq − meanq, θ′ = TSCAL·totalθ −
meanθ, H′/psi′ = total − mean (in nondimensional space). If a piecewise sum
over inversions is intended to reconstruct the total perturbation, the NOUT
piece lists must partition {1..NL} and INLIN must be 1.

### pert.out layout, FORMAT(13F10.2)

Header, then for each of the NOUT inversions in deck order, with no
separators:

| block | count | content |
|-------|-------|---------|
| HP | NHO × NY×NX | perturbation height induced by that inversion's PV pieces, at levels HOUT(1..NHO) in ascending K, **meters** (multiplied by HNDM on write) |
| SP | NSIO × NY×NX | induced perturbation streamfunction at levels SIOUT(1..NSIO), 10⁵ m²/s (h.out psi convention) |

So the shipped 3-inversion deck produces 3 × (10 + 10) = 60 blocks.

### IBC=2 initial-guess file (IGFIL) contract

* The filename is read into `CHARACTER*30 IGFIL` — **at most 30 characters**.
  Use relative paths and run from inside the run directory (the five FNM main
  deck names are CHARACTER*50, so only IGFIL is this tight).
* File format, all free-format (any line wrapping):
  1. header line(s): 8 values (same convention as every other file);
  2. HP at **all NL levels** (NY×NX each, bottom -> top);
  3. SP at **all NL levels**.
* Values are in **meters** (the code divides by HNDM on read). This is
  exactly the pert.out convention, so a coarse/outer-domain pert.out
  subsetted to the inner grid is a valid IGFIL provided all 2·NL levels are
  present (the deck writing it must list every level in HOUT/SIOUT). The HP
  read has no END guard — a short file aborts; the SP read tolerates
  truncation but leaves unread levels undefined, so always supply all 2·NL.
* Both interior and boundary values are used: the interior is the SOR initial
  guess, the boundary ring supplies the fixed lateral boundary condition
  ("nesting" a small-domain inversion inside a larger one).

## 7. Regression against the shipped tutorial outputs

Method: run reg10 binaries on the shipped inputs, parse outputs numerically
(fixed 10-char fields after the free-format header) and compare block-wise
against the shipped outputs. Per-day outputs of pvpialln do not depend on
nhalfday, so a 1-day run must reproduce the shipped per-day files.

(a) `pvpialln10`, input `03021200.grid`, nhalfday=1, output day 1
vs shipped `03021200q.out` / `03021200h.out`:

| file | block | n | max abs diff | RMS diff |
|------|-------|---|--------------|----------|
| q.out | THB | 945 | 0.0000 | 0.000000 |
| q.out | THT | 945 | 0.0000 | 0.000000 |
| q.out | Q (K=2..9) | 7560 | 0.0100 | 0.000115 |
| h.out | H | 9450 | 0.0000 | 0.000000 |
| h.out | psi (/1e5) | 9450 | 0.0200 | 0.003605 |
| h.out | U | 9450 | 0.0000 | 0.000000 |
| h.out | V | 9450 | 0.0000 | 0.000000 |
| h.out | TH | 9450 | 0.0000 | 0.000000 |

Structure matches exactly; psi SOR converged in 95 iterations (< the original
300 cap, so the cap bump cannot alter reg10 results). Diffs are at the last
written F10.2 digit (0.01 of 0.01 PVU for Q; 0.02×10⁵ m²/s for psi), i.e.
compiler-rounding-level agreement with the 1990s binaries.

(b) `qinvert10`, deck = shipped `qinvert21_94_in` pattern with inputs
`03021200h.out` + `03021200q.out` (MAX/MAXT/OMEGAS/OMEGAH/PRT/THR =

|-------|---|--------------|----------|
| HZ | 9450 | 0.0200 | 0.004467 |
| SI | 9450 | 0.0200 | 0.004705 |

(c) `qinvertp10` zero-perturbation smoke test: meanq = shipped q.out,
meanh = header + first two blocks (H, psi) of shipped h.out, total q =
shipped q.out, total h = shipped bal.out; one inversion, QLV list = level 1
only, IBC=0, INLIN=1, IQD=0. Converged (1 SOR iteration per level, TOTAL
CONVERGENCE); output max |value| = **0.0** exactly across all 18900 output
